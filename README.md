# HTTP Demo Testing APIs (Mini Airbnb Backend)

This project is a **Spring Boot backend demo** created to understand:

- REST API development
- Swagger API documentation
- In-memory API testing (without database)
- Load testing using k6
- Multi-endpoint performance testing

The system simulates a **Mini Airbnb-style backend** containing Users, Properties, Bookings, and Payments APIs.

---

## Tech Stack

- Java 17
- Spring Boot
- Swagger / OpenAPI
- Maven
- k6 (Load Testing)

---

## Project Modules

- Users API
- Property API
- Booking API
- Payment API

Each module exposes REST endpoints for testing API workflows.
